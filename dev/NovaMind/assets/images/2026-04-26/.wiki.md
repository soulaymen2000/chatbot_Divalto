# Project Summary
NovaMind is a modern web application designed to provide a unique AI chat experience, similar to ChatGPT or Claude, but with a polished and distinctive UI/UX. The project focuses on creating a fully responsive design with features such as dark/light mode toggling, session-based UI, and a clean, minimal user experience. It aims to facilitate intelligent conversations through a user-friendly interface while ensuring scalability for future backend integration.

# Project Module Description
- **Authentication**: User sign-in and sign-up functionality.
- **Chat Interface**: A dynamic chat interface that supports conversation history, typing indicators, and message bubbles.
- **Sidebar**: A collapsible sidebar for navigating between conversations.
- **Theme Toggle**: Functionality to switch between dark and light themes.

# File Description Inventory
- **README.md**: Overview and setup instructions for the project.
- **package.json**: Lists dependencies and scripts for building and running the application.
- **src/index.tsx**: Entry point of the React application.
- **src/App.tsx**: Main application routing and layout.
- **src/pages**: Contains individual page components for authentication and chat functionalities.
- **src/components**: Reusable UI components for the chat interface and other UI elements.
- **src/lib**: Contains the Zustand store for state management and other utility functions.
- **src/hooks**: Custom hooks for managing component behavior.

# Technology Stack
- **React**: Frontend library for building user interfaces.
- **Zustand**: State management library for managing application state.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Vite**: Build tool for fast development and optimized production builds.

# Usage
To set up the project, follow these steps:
1. Install dependencies:
   ```
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the application:
   ```
   pnpm run lint
   ```
